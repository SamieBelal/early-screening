# The Earlier, The Better

A one-page resource for parents worried about their child's development: milestone tracking, autism screening, and how to reach Early Intervention.

Static HTML, hosted on GitHub Pages. Edit `index.html` and push to `main` to update the site.

The page links to official resources only. The M-CHAT-R/F is not reproduced here; posting it on a website requires a license from its authors (see mchatscreen.com).
